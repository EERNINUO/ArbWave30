## 1. 板卡概述
- 功能定位：控制模拟板的波形生成、与PC进行USB通信、调理输入电源供给模拟板、人机交互。
- 关键性能指标：功耗、尺寸、环境要求
  - 功耗：< 5W（不包括供给模拟板的电源）
  - 尺寸：< 100mm x 100mm
  - 环境要求：0 \~ 40 ℃
- 主要接口：
  - 对外连接器：
    - 电源输入：DC2.1mm 
    - USB 接口：USB Type-B
  - 板间接口：见[板间接口文档](./板间接口设计文档.md)

## 2. 模块详细设计
### 2.1 MCU 最小系统
- **原理图截图**：![MCU最小系统](/docs/pic/MCU最小系统.png)
  
- **功能描述**：
  作为整个控制板的核心，负责处理 USB 通信、解析 SCPI 命令、控制 FPGA 配置、管理用户接口（按键/编码器）以及存储用户设置。
- **关键器件**：
  
| 器件 | 型号 | 特性 | 选型理由 |
|------|-----|------|---------|
| MCU | STM32F411CEU6 | ARM Cortex-M4F, 512KB Flash, 128KB RAM | 性能满足需求，成本合理 |

- **具体设计**：
  - 电源：
    - VDD: 3.3V，一个单独的10uF电容 + 每一个单独的 VDD 就近放置一个 100 nF 的陶瓷电容, 靠近芯片布局
    - VDDA: 3.3V，就近放置单独的1uF电容 + 100 nF陶瓷电容，靠近芯片布局 <!-- 锁相环是不是用这玩意供电的？ -->
    - VBAT: 3.0V，连接到CR2032电池座，提供实时时钟和备份寄存器电源，通过电源切换电路实现自动切换，当主电源断电时自动切换到电池供电，保证 RTC 和备份寄存器的数据不丢失。
    - VCAP: 连接到一个就近放置的 4.7uF 陶瓷电容，提供内部 LDO 稳压器的稳定电压。
    - VSSA/GND: 通过花焊盘连接到地平面，确保良好的接地
  - 时钟：
    - HSE：外部晶振 8MHz，尽量靠近MCU，内部 PLL 生成 96MHz 系统时钟，匹配电容根据数据手册选型。
    - LSE：外部晶振 32.768kHz，提供 RTC 时钟源，匹配电容根据数据手册选型。
  - 复位：复位引脚连接到调试接口的排针，由调试器控制，并通过一个 100nF 电容连接到地，一个 10kΩ 上拉电阻连接到 VDD（数据手册指出NRST内部已经有了约 40kΩ 的上拉电阻，但噪声环境下不一定可靠，故保留外部上拉电阻焊盘，根据具体情况调整）。
  - 调试接口：7针 2.54mm 排针，合并 SWD 和调试串口(USART1)，用于调试和烧录。
  - Boot 配置：Boot0 默认通过 10kΩ 下拉到地，需要从bootloader模式烧录时，使用按键短接 BOOT0 引脚到 3.3V。
  - SPI1: 连接到板间连接器，MOSI/CLK靠近MCU端串联 22Ω 串阻，MISO不加串联电阻，供 FPGA 控制使用。

- **接口信号**：列出输入/输出信号名称、电平、阻抗、时序要求
  | 信号名 | 方向 | 协议 | 连接到 | 备注 |
  |--------|------|------|--------|------|
  | SWDIO/SWCLK | 双向 | SWD | 调试器（ST-Link） | 用于调试和烧录 |
  | USB DP/DM | 双向 | USB 2.0 FS | USB 接口 | 差分信号，90Ω阻抗 | 
  | SPI1 | 双向 | SPI | FPGA 配置 | MOSI/CLK靠近MCU端串联 22Ω 串阻 |
  | GPIO | 输出 | GPIO | 蜂鸣器 | 三极管扩流 |  
  | IIC | 双向 | IIC | EEPROM | 100kHz |
  | UART | 双向 | UART | 调试串口 | 115200 baud rate |
  
- **保护设计**：
  - SPI1 接口：MOSI/CLK靠近MCU端串联 22Ω 串阻，MISO不加串联电阻，焊盘设计允许焊接 0Ω 电阻或直接短接。
  - USB 接口：见[USB 接口](#USB接口)部分。
  
- **测试点**： 
  - SPI1_SCK/MOSI/MISO/CS：用于示波器观察 SPI 信号质量和时序。
  - IIC_SDA/SCL：用于观察 I2C 通信波形

### 2.2 USB 接口{#USB接口}
 - **原理图截图**: ![USB 接口](/docs/pic/USB接口.png)
- **功能描述**：
  - 通过 USB-FS 接收 SCPI 命令
  - 通过 USB-FS 发送响应数据
  - 自动检测线缆插入
- **关键器件**：

| 器件 | 型号 | 特性 | 选型理由 |
|------|-----|------|---------|
| USB 接口 | USB Type-B | 4线母头 USB2.0 | 连接稳定，可靠性高，行业标准 |
| ESD 芯片 | PRTR5V0U2X | 超低电容双轨对轨ESD芯片 | 保护USB接口 |

- **接口信号**：
  | 信号名 | 方向 | 协议 | 连接到 | 备注 |
  |--------|------|------|--------|------|
  | USB_DP/DM | 双向 | USB 2.0 FS | PC | CDC |
  | VBUS | 输入 | 电平 | MCU GPIO | USB 连接检测 |

- **具体设计**：
  - USB DP/DM 走差分线，阻抗控制在 90Ω，长度匹配，避免放置过孔, 靠近接口处放置 ESD 保护芯片。
  - USB 串联 22Ω 串阻可减少反射和 EMI，但ST官方不建议添加，保留焊盘，靠近 MCU 端，但焊接0Ω电阻或直接短接。
  - GND 与板卡地平面直接连接。
  - 连接器外壳通过花焊盘与地连接，提供额外的屏蔽和接地路径。
  - VBUS 线通过分压电阻分压到3.3V后连接到 MCU 的 GPIO，用于检测 USB 连接状态。
  - DP 上拉由 MCU 内部实现，无需外部 1.5k 电阻，软件配置即可。

- **保护设计**：ESD、过流、过压、防反接等
  - ESD 保护：USBLC6-4SC6Y 汽车级芯片，低电容，保护 USB DP/DM 线免受静电放电损伤。
  - 过流保护：USB 供电线（VBUS）只做检测，不直接供电，避免过流风险。
  - 防反接：USB 接口本身设计为防反插，内部电路不需要额外防反接措施。
  
- **测试点**：
  - TP_USB_DP/DM：用于示波器观察 USB 信号质量和时序。
  - TP_USB_VBUS：用于测量 USB 连接状态电压，验证连接检测功能。

## 3. PCB 布局与布线指南
### 3.1 层叠结构
  - 层数：4 层
  - 层序：
    - Top：信号 + 电源局部走线 + 元件
    - Inner1：完整地平面（GND）
    - Inner2：电源分割层（+3.3V_D, +18V_M, -18V_M 等）
    - Bottom：信号 + 少量地线 + 辅助电源走线
  - 厚度：1.6mm 总厚，50Ω 单端走线宽度计算（例如 0.25mm 线宽，参考地平面）。
  - 铜厚：1oz（35μm）内外层。

### 3.2 整体布局原则
1. 按功能分区
  - 电源输入区（DC 插座、TVS、防反接、DC-DC）
  - MCU 区（STM32、晶振、SWD、USB）
  - 连接器区（到模拟板的排针、触发 SMA）
  - 预留扩展区（按键、TFT 排针）

2. 电源路径
  - DC 输入 → 保险丝/TVS → 防反接 → 大电容（100μF） → DC-DC 输入。
  - DC-DC 输出电容紧贴电感输出端。
  - 电源走线先经过电容再到负载。

3. 热管理
  - DC-DC 芯片底部打过孔散热，顶层铺铜加阻焊开窗。
  - 电感下方禁止走敏感信号线。

4. 接口位置
  - USB 连接器放板边，方便插拔。
  - 连接器（到模拟板）集中放置，保证排针间距匹配。
  - SMA 触发口放板边，远离 DC-DC。

### 3.3 关键模块布线约束

| 模块 | 约束 | 说明 |
|------|------|------|
| USB (DP/DM) | 差分阻抗 90Ω，线宽/间距根据叠层计算；等长误差 < 1mm；远离 DC-DC 和时钟 |  |
| SWD 调试口 | 靠近 MCU，CLK 串 22Ω 电阻，避免长线 | 便于烧录 |
| 晶振 (8MHz) | 距离 MCU OSC_IN/OUT < 5mm，包地，底部不走信号线，外壳接地 | 减少辐射 |
| DC-DC 开关节点 | 走线尽量短而宽，SW 节点不铺铜过大，反馈电阻紧贴 FB 引脚 | 降低 EMI |
| 板间连接器信号 | SPI、I2C、复位信号并行走线时，彼此间距 > 3 倍线宽；下方参考地连续 | 避免串扰 |

### 3.4 地平面处理
- 整个数字板单点接地：所有地直接通过过孔连接到 Inner1 地平面，不分割。
- DC-DC 的功率地（PGND）与信号地（AGND）在芯片下方单点连接（通过 0Ω 电阻或铜皮直接相连）。
- 连接器处的 GND 引脚至少安排 30% 以上，分散排布。

### 3.5 电源完整性
  - 每个 IC 电源引脚：一个 0.1μF + 一个 1μF 电容，尽量放在同一面且紧贴引脚。
  - 板间连接器附近放置 10μF 和 0.1μF 电容，为模拟板提供干净的供电入口。
  - 使用 电源层分割：+3.3V_D 走内层大面积，+18V_M 与 -18V_M 走顶层或底层加宽走线（> 1.5mm）。

### 3.6 可测试性设计
  - 预留测试点：+18V_M, -18V_M, +3.3V_D, GND, SPI_CLK, SPI_MOSI, 连接器的关键信号。
  - 测试点形式：直径 1mm 的圆形露铜焊盘，加过孔增强固定。

### 3.7 布线检查清单（供自检）
  - 所有电源输入有足够电容。
  - 晶振负载电容走线尽量短，无多余分支。
  - USB 差分线附近无开关电源电感。
  - 连接器附近无长距离平行敏感信号。
  - DC-DC 输出纹波在预期内（用示波器实测）。

## 4. 测试与调试
### 4.1 测试点位置
所有电源轨、关键信号线（如 SPI 总线、USB DP/DM）预留测试点
### 4.2 上电前检查清单（短路测试、电源电压测量）
### 4.3 单板独立测试步骤：
分步上电：先焊电源部分，验证各电压轨；再焊STM32，烧录代码；接着焊外设验证USB，EEPROM等是否正常，最后焊连接器，测试与模拟板的通信。
关键波形测试点：
  - USB DP/DM 波形（示波器观察）
  - SPI 信号（时钟、数据）波形
模块测试：
  - 电源测试（空载、负载纹波）
  - 数字通信环回测试（SPI、I2C）
  - 模拟通道静态测试（DAC 输出固定码、测量电压）
  - 动态测试（用示波器观察波形）
- 常见故障排查指南
