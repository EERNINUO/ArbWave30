## 3. 板间通信协议（MCU ↔ FPGA）
### 3.1 物理层
| 参数 | 规格 | 备注 |
|------|------|------|
| 接口 | SPI | 4线制（CS、SCK、MOSI、MISO） |
| 工作模式 | Mode 0 | CPOL=0, CPHA=0（SCK空闲低电平，上升沿采样） |
| 最大时钟频率 | 10 MHz | 受板间连接器排线长度限制 |
| 数据位序 | MSB First | 每字节内高位先传输 |
| 字节序 | Little-Endian | 多字节数值低字节在前（与STM32原生一致）|
| 逻辑电平 | 3.3V LVCMOS | 与FPGA Bank电压匹配 |
> **硬件连接**：具体引脚定义参见[《板间接口设计文档》第3.2节 信号连接器 (J_SIG)](/docs/硬件设计文档/板间接口设计文档.md#3.2-信号连接器-J_SIG)。

### 3.2 协议帧格式
寻址（1 Byte） -> 数据内容（2 Bytes） -> CRC8 -> ACK（1 Byte）

![alt text](pic/SPI协议帧.drawio.png)

#### 3.2.1 寻址字节

| 位 | 功能描述 | 备注 |
|-----|------|------|
| bit7 | R/W# | 0 = 写操作（MCU → FPGA），1 = 读操作（FPGA → MCU） |
| bit6\~0 | 寄存器地址 | 寄存器地址（0~127），详见第3.3节寄存器映射表 |

#### 3.2.2 数据内容
所有寄存器统一为 16 位宽度。多字节传输时采用小端序：
  - 最低有效字节（LSB）最先出现在MOSI线上
  - 最高有效字节（MSB）最后出现
示例：写入 0x1234 到地址0x00时，MOSI上的字节序列为：
```text
[0x00]   [0x34][0x12]   [CRC_H]
 地址   数据域（小端序）   CRC16
```

#### 3.2.3 CRC8校验
算法：CRC-8
多项式：0x07（$X^8 + X^2 + X^1 + 1$）
初始值：0x00
计算范围：从寻址字节开始，到数据内容的最后一个字节结束，不包含CRC本身。

#### 3.2.4 ACK字节
| 位 | 功能描述 | 备注 |
|-----|------|------|
| bit7~4 | - | 保留 |
| bit3 | CRC_ERR | CRC 校验错误 |
| bit2 | BUSY | FPGA 忙 |
| bit1 | ADDR_ERR | 寄存器地址错误 |
| bit0 | ACK | 应答标志 |
```verilog
  bit0 = ~( | bit[7:1] )
``` 

### 3.3 寄存器映射表（Register Map）
寄存器映射采用绝对地址映射，将地址空间划分为三个功能区域，避免通道与全局控制耦合。
所有寄存器都是 16 位宽，保留位写入时应保持为0。

#### 3.3.1 寄存器映射总表
区域 A：系统/全局寄存器 (地址 0x00 ~ 0x0F) 
| 地址 | 名称 | 描述 |
|------|------|------|
| 0x00 | SYS_ID | 设备标识。固定返回 0x4157 (ASCII "AW") |
| 0x01 | SYS_CTRL | 系统控制 (时钟源、软复位等) |
| 0x02 | SYS_STATUS | 系统状态 (PLL锁定、温度告警等) |
| 0x03 ~ 0x0F | Reserved | - |

区域 B：通道1寄存器 (地址 0x10 ~ 0x1F) 
| 地址 | 名称 | 描述 |
|------|------|------|
| 0x10 | CH1_CTRL | 通道1控制 (波形选择、输出使能等) |
| 0x11 | CH1_FREQ_H | 通道1频率控制字高 16 位 |
| 0x12 | CH1_FREQ_M | 通道1频率控制字中 16 位 |
| 0x13 | CH1_FREQ_L | 通道1频率控制字低 16 位 |
| 0x14 | CH1_AMPL | 通道1幅值控制字 |
| 0x15 | CH1_OFFSET | 通道1偏置控制字 |
| 0x16 | CH1_PHASE | 通道1相位控制字 |
| 0x17 ~ 0x1F | Reserved | - |

区域 C：通道2寄存器 (地址 0x20 ~ 0x2F) 
| 地址 | 名称 | 描述 |
|------|------|------|
| 0x20 | CH2_CTRL | 通道2控制 (波形选择、输出使能等) |
| 0x21 | CH2_FREQ_H | 通道2频率控制字高 16 位 |
| 0x22 | CH2_FREQ_M | 通道2频率控制字中 16 位 |
| 0x23 | CH2_FREQ_L | 通道2频率控制字低 16 位 |
| 0x24 | CH2_AMPL | 通道2幅值控制字 |
| 0x25 | CH2_OFFSET | 通道2偏置控制字 |
| 0x26 | CH2_PHASE | 通道2相位控制字 |
| 0x27 ~ 0x2F | Reserved | - |

区域 D: DAC 寄存器映射 (地址 0x30 ~ 0x3B，对应 DAC 寄存器 0x00 ~ 0x12)
| 映射地址 | 原地址 | 名称 |
|---------|--------|------|
| 0x30 | 0x00 | SPIControl |
| 0x31 | 0x02 | Data Control |
| 0x32 | 0x03 | PowerDown |
| 0x33 | 0x0A | DAC Mode Select |
| 0x34 | 0x0B | DAC1 Gain LSB |
| 0x35 | 0x0C | DAC1 Gain MSB |
| 0x36 | 0x0D | AUX DAC1 LSB |
| 0x37 | 0x0E | AUX DAC1 MSB |
| 0x38 | 0x0F | DAC2 Gain LSB |
| 0x39 | 0x10 | DAC2 Gain MSB |
| 0x3A | 0x11 | AUX DAC2 LSB |
| 0x3B | 0x12 | AUX DAC2 MSB |

## 4. MCU 固件详细设计
### 4.1 任务/状态机划分
列出主要任务：
- USB 数据处理任务（SCPI 命令接收、响应发送）
- SCPI 命令解析与执行任务

- 按键扫描及去抖任务（未来）=- 显示更新任务（未来）
- EEPROM 参数保存/恢复任务

### 4.2 SCPI 解释器设计
状态机：采用 SCPI-1999 推荐的状态机（命令树遍历）。

支持的子系统（ V1.0 必须实现的）：

```text
*IDN?, *RST, *CLS
SOURce[1]:FUNCtion {SIN|SQU|TRI|SAW|STEp|DC}
SOURce[1]:FREQuency {<value>}
SOURce[1]:VOLTage {<value>} (Vpp)
SOURce[1]:VOLTage:OFFSet {<value>}
OUTPut[1]:STATe {ON|OFF}
SYSTem:ERRor?
```

命令解析流程：接收字符 → 词法分析 → 查找命令树节点 → 执行回调 → 生成响应。

### 4.4 非易失存储

触发条件：参数改变后延时 5 秒写入 EEPROM。
上电恢复：读取 EEPROM 并恢复至 FPGA。

### 5.2 DDS 关键参数计算
系统时钟 Fclk = 150MHz
相位累加器位宽 N = 48
频率控制字 FTW = round( f_out × 2^N / Fclk )
<!-- 给出计算示例：f_out = 30MHz → FTW ≈ 30e6 × 2^48 / 150e6 = 0x28F5C28F5C28F5（可截断低8位？建议保留48位，精度满足1μHz）。 -->

### 5.3 波形生成
正弦波：查表（至少 4096 点，16bit 输出）。
方波：相位累加器 MSB 直接输出（再经幅度控制）。
三角波：相位累加器低 N-1 位经折叠变换。
锯齿波：直接取相位累加器高 14 位。
阶梯波：自定义（如每 16 个时钟改变一次输出值）。

### 5.4 DAC 时序
- 数据更新：在每个DCO上升沿，将 dac_data 输出到引脚并保持满足建立时间。
- 双通道，参考 AD9747 数据手册的并行模式。

### 5.5 SPI 从机接口
时钟速度 ≤ 10MHz。
状态机：空闲 → 接收命令码 → 接收参数 → 更新寄存器 → 发送 ACK（可选）。
