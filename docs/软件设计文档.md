## 3 SPI 通信协议（MCU ↔ FPGA）
### 3.1 通信模式
位序：MSB First
字节序：小端序，低字节在前
SPI 模式：模式 0（CPOL=0，CPHA=0）

### 3.2 协议帧格式
寻址（1 Byte） -> 参数数据（2 Bytes） -> CRC8 -> ACK（1 Byte）

![alt text](pic/SPI协议帧.drawio.png)

CRC8计算范围：从寻址字节开始，到参数数据的最后一个字节结束，不包含CRC本身。
CRC8多项式：0x31（x^8 + x^5 + x^4 + 1）

### 3.3 协议帧内容
#### 3.3.1 寻址字节
地址含义：
| 位 | 功能 |
|-----|------|
| bit7 | 回读（1: 回读，0: 写入）（V1.0暂不实现） |
| bit6 | 通道选择（0: 通道1，1: 通道2） |
| bit5 | 保留（0）|                       
| bit4\~0 | 寄存器地址 |

寄存器表：
| 寄存器地址 | 名称 | 清零值 | 功能 |
|------|------|------|
| 0x00 | FREQ_H | 0x00 | 频率控制字高 16 位 |
| 0x01 | FREQ_M | 0x00 | 频率控制字中 16 位 |
| 0x02 | FREQ_L | 0x00 | 频率控制字低 16 位 |
| 0x03 | AMPL | 0x00 | 幅值控制字 |
| 0x04 | OFFSET | 0x00 | 偏置控制字 |
| 0x05 | CTRL | 0x00 | 控制寄存器 |

#### 3.3.2 应答表
| 位 | 名称 | 功能 |
|------|------|------|
| bit7~4 | - | 保留 |
| bit3 | CRC_ERR | CRC 校验错误 |
| bit2 | BUSY | FPGA 忙 |
| bit1 | ADDR_ERR | 寄存器地址错误 |
| bit0 | ACK | 应答标志 |

> bit0 = ~( |bit[7:1] )

### 4.1 任务/状态机划分
列出主要任务：

- EEPROM 参数保存/恢复任务

### 4.2 SCPI 解释器设计
状态机：采用 SCPI-1999 推荐的状态机（命令树遍历）。

支持的子系统（ V1.0 必须实现的）：

```text
*IDN?, *RST, *CLS
SOURce[1]:FUNCtion {SIN|SQU|TRI|SAW|STEp|DC}
SOURce[1]:FREQuency {<value>}
SOURce[1]:VOLTage {<value>} (Vpp)
SOURce[1]:VOLTage:OFFSet {<value>}
OUTPut[1]:STATe {ON|OFF}
SYSTem:ERRor?
```

命令解析流程：接收字符 → 词法分析 → 查找命令树节点 → 执行回调 → 生成响应。

### 4.3 USB 协议栈
实现 USBCDC 类<!-- （说明选型理由，如 libopencm3 或 ST USB 库） -->
端点配置、包大小、接收/发送缓冲区管理
与 SCPI 解析器的接口（字符流）

### 4.4 非易失存储
存储内容：输出状态（ON/OFF）、输出阻抗、最近一次波形/频率/幅值/偏置。
触发条件：参数改变后延时 5 秒写入 EEPROM。
上电恢复：读取 EEPROM 并恢复至 FPGA。

### 5.2 DDS 关键参数计算
系统时钟 Fclk = 150MHz
相位累加器位宽 N = 48
频率控制字 FTW = round( f_out × 2^N / Fclk )
<!-- 给出计算示例：f_out = 30MHz → FTW ≈ 30e6 × 2^48 / 150e6 = 0x28F5C28F5C28F5（可截断低8位？建议保留48位，精度满足1μHz）。 -->

### 5.3 波形生成
正弦波：查表（至少 4096 点，16bit 输出）。
方波：相位累加器 MSB 直接输出（再经幅度控制）。
三角波：相位累加器低 N-1 位经折叠变换。
锯齿波：直接取相位累加器高 14 位。
阶梯波：自定义（如每 16 个时钟改变一次输出值）。

### 5.4 DAC 时序
- 数据更新：在每个DCO上升沿，将 dac_data 输出到引脚并保持满足建立时间。
- 双通道，参考 AD9747 数据手册的并行模式。

### 5.5 SPI 从机接口
时钟速度 ≤ 10MHz。
状态机：空闲 → 接收命令码 → 接收参数 → 更新寄存器 → 发送 ACK（可选）。
