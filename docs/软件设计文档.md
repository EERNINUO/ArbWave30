## 3. 板间通信协议（MCU ↔ FPGA）
### 3.1 物理层
| 参数 | 规格 | 备注 |
|------|------|------|
| 接口 | SPI | 4线制（CS、SCK、MOSI、MISO） |
| 工作模式 | Mode 0 | CPOL=0, CPHA=0（SCK空闲低电平，上升沿采样） |
| 最大时钟频率 | 10 MHz | 受板间连接器排线长度限制 |
| 数据位序 | MSB First | 每字节内高位先传输 |
| 字节序 | Little-Endian | 多字节数值低字节在前（与STM32原生一致）|
| 逻辑电平 | 3.3V LVCMOS | 与FPGA Bank电压匹配 |
> **硬件连接**：具体引脚定义参见[《板间接口设计文档》第3.2节 信号连接器 (J_SIG)](/docs/硬件设计文档/板间接口设计文档.md#3.2-信号连接器-J_SIG)。

### 3.2 协议帧格式
寻址（1 Byte） -> 数据内容（2 Bytes） -> CRC8 -> ACK（1 Byte）

![alt text](pic/SPI协议帧.drawio.png)

#### 3.2.1 寻址字节

| 位 | 功能描述 | 备注 |
|-----|------|------|
| bit7 | R/W# | 0 = 写操作（MCU → FPGA），1 = 读操作（FPGA → MCU） |
| bit6\~0 | 寄存器地址 | 寄存器地址（0~127），详见第3.3节寄存器映射表 |

#### 3.2.2 数据内容
所有寄存器统一为 16 位宽度。多字节传输时采用小端序：
  - 最低有效字节（LSB）最先出现在MOSI线上
  - 最高有效字节（MSB）最后出现
示例：写入 0x1234 到地址0x00时，MOSI上的字节序列为：
```text
[0x00]   [0x34][0x12]   [CRC_H]
 地址   数据域（小端序）   CRC16
```

#### 3.2.3 CRC8校验
算法：CRC-8
多项式：0x07（$X^8 + X^2 + X^1 + 1$）
初始值：0x00
计算范围：从寻址字节开始，到数据内容的最后一个字节结束，不包含 CRC 和 ACK 字节。

#### 3.2.4 ACK字节
| 位 | 功能描述 | 备注 |
|-----|------|------|
| bit7~4 | - | 保留（默认为0） |
| bit3 | CRC_ERR | CRC 校验错误 |
| bit2 | BUSY | FPGA 忙 |
| bit1 | ADDR_ERR | 寄存器地址错误 |
| bit0 | ACK | 应答标志，当且仅当 bit7~bit1 全部为 0 时，该位为 1 |
```verilog
  bit0 = ~( | bit[7:1] )
``` 

### 3.3 寄存器映射表（Register Map）
寄存器映射采用绝对地址映射，将地址空间划分为三个功能区域，避免通道与全局控制耦合。
所有寄存器都是 16 位宽，保留位写入时应保持为0。

#### 3.3.1 寄存器类型
| 类型 | 描述 | 备注 |
|------|------|------|
| R | 只读 | 不可写入，只读 |
| RW | 读写 | 可读写 |
| RWC | 读清除 | 读操作后自动清零 |
| WS | 自清零 | 完成操作后自动清零 |
| W1C | 写1清除 | 写1清除对应位，不可读 |

> **频率/相位/幅值/偏置寄存器（0x11~0x16, 0x21~0x26）均为“影子寄存器”**。
MCU 写入这些寄存器后，FPGA 内部主 DDS 参数**不会立即更新**。
只有当 MCU 向 SYS_CTRL -> UPDATE 位写 1 时，FPGA 才会将所有影子寄存器的值一次性原子性地加载到 DDS 内核。

> MCU 写 0x30~0x3B 时，只修改 FPGA 内部的 DAC 影子缓存，**不触发 SPI 传输**。
> 只有当 MCU 向 SYS_CTRL -> DAC_CMD_WRITE 写 1 时，FPGA 才将这些缓存值**一次性通过 SPI 口刷到 AD9747 中。**

 > **CS 拉低时接收到的数据视为一帧。**
 若 CS 拉低时间段内未能收满一帧数据或未成功发送 ACK 字节，则认为该帧无效，FPGA 不做任何处理。
 若 CS 拉低后接收的数据量超出一帧数据，则超出部分无效。
 若 CS 拉低后 1ms 内传输未完成，则认为该帧无效。
### 3.5 错误处理
### 3.5 错误处理与重试策略

本协议采用 **“帧内即时反馈 + 帧间超时重传”** 的双重错误处理机制。

#### 3.5.1 错误分类与 FPGA 响应

| 错误类型 | 触发条件 | FPGA 行为 | ACK 反馈 |
|----------|----------|-----------|----------|
| **帧长度错误** | CS 拉低期间，字节数 ≠ 4 (地址+数据+CRC) 或 CS 低电平持续时间 > 1ms | 静默丢弃当前帧，寄存器保持不变 | 不发送 ACK（MISO 保持高阻或拉低） |
| **CRC 校验失败** | 接收到的 CRC 与本地计算值不匹配 | 静默丢弃当前帧，寄存器保持不变 | `bit3=1` (CRC_ERR)，`bit0=0` |
| **地址越界** | 地址字节 bit6~0 > 0x3F（超出映射表范围） | 静默丢弃 | `bit1=1` (ADDR_ERR)，`bit0=0` |
| **FPGA 忙** | 上一帧正在处理中 | 忽略新帧，保持不变 | `bit2=1` (BUSY)，`bit0=0` |

#### 3.5.2 MCU 端处理流程

MCU 在发送完完整帧（地址+数据+CRC）后，必须在**下一个字节（即 ACK 字节）**的 SCK 上升沿采样 MISO 线。

1. **正常情况**：读取 ACK = `0x01`，操作成功，结束流程。
2. **BUSY 情况**：若读取 `bit2=1`，MCU 应等待 100μs 后重新发送**完全相同**的帧（不增加重试计数，因为这是FPGA暂时的处理延迟）。
3. **CRC_ERR**：若读取 `bit3=1`，MCU 应立即重新发送**完全相同**的帧。
4. **ADDR_ERR**：表明帧格式非法。MCU 应立即停止重传，向上层 SCPI 层报告硬件错误（错误码 `-241`，“硬件故障”），防止恶性循环。
5. **超时情况**：若 CS 拉低后 1ms 内未收到任何 ACK（或 MISO 一直为低），MCU 应视为通信超时。

#### 3.5.3 重试策略

- **最大重试次数**：3 次（针对超时，CRC_ERR 和 BUSY 状态）。
- **重试间隔**：500μs。
- **最终失败**：若 3 次重试均失败，MCU 必须：
  1. 尝试关闭当前通道输出（设置 CHx_CTRL.ENABLE = 0）以保护负载。
  2. 向上位机返回 SCPI 错误 `-241`（“FPGA 通信超时/错误”）。
  3. 置位内部错误标志位，直到收到 `*CLS` 命令前不再尝试下发参数（但允许继续尝试读取状态寄存器以排查问题）。

#### 3.5.4 特殊场景：影子寄存器更新失败

当 MCU 写入 `SYS_CTRL.UPDATE = 1` 后，FPGA 开始加载影子寄存器。
- 由于这是一个内部操作（耗时 < 1μs），MCU **不需要**等待 ACK 确认加载完成。
- MCU 可通过回读 `SYS_CTRL.UPDATE` 寄存器确认硬件是否已自动清零；若长时间（如 10ms）未清零，应视为 FPGA 内部逻辑异常，执行硬件复位（拉低 FPGA_NRST）。

## 5. FPGA 逻辑详细设计
### 5.1 模块划分
sys_ctrl：系统控制模块，控制 FPGA 的时钟、复位等。
wave_generation: 波形控制模块，根据配置寄存器生成波形。
dac_interface：DAC 接口模块，将波形数据从 FPGA 时钟域搬运到 AD9747 时钟域；
spi_master：对 AD9747 与 DAC8562 进行 SPI 控制。
spi_slave：接收 MCU 命令，更新配置寄存器。
register_block：配置寄存器模块，存储系统状态和参数等。
afe_control：输出衰减、输出阻抗继电器的控制信号.

### 5.2 DDS 关键参数计算
系统时钟 Fclk = 150MHz
相位累加器位宽 N = 48
频率控制字 FTW = round( f_out × 2^N / Fclk )

### 5.3 波形生成
正弦波：查表（至少 4096 点，16bit 输出）。
方波：相位累加器 MSB 直接输出（再经幅度控制）。
三角波：相位累加器低 N-1 位经折叠变换。
锯齿波：直接取相位累加器高 14 位。
阶梯波：自定义（如每 16 个时钟改变一次输出值）。

### 5.4 DAC 时序
- 数据更新：在每个DCO上升沿，将 dac_data 输出到引脚并保持满足建立时间。
- 双通道，参考 AD9747 数据手册的并行模式。

### 5.5 SPI 从机接口
时钟速度 ≤ 10MHz。
状态机：空闲 → 接收命令码 → 接收参数 → 更新寄存器 → 发送 ACK（可选）。
